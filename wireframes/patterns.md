# Wireframes — 레이아웃 패턴 스펙

각 패턴은 `content/deck.json`의 슬라이드 `type`과 1:1로 대응하고,
`components/index.js`의 동명 함수가 구현한다.
새 패턴 추가 = ① 여기에 스펙 작성 → ② 컴포넌트 구현 → ③ deck.json에서 사용.

좌표는 모두 12컬럼 그리드(`colX/colW`) 기준. 임의 좌표 금지.

---

## cover — 표지 (다크)

```
┌──────────────────────────────────────┐
│ (장식 반투명 서클, 우상/좌하)          │
│                                      │
│   KICKER (ice, 자간+3)               │
│   타이틀 2줄 (white 44 bold)          │
│   서브타이틀 (ice 14)                 │
│                                      │
│   워드마크          ·        비고     │
└──────────────────────────────────────┘
```
슬롯: `kicker, title(\n 허용), subtitle, footnote` / meta에서 `company`

## agenda — 목차 (좌 타이틀 + 우 리스트)

```
┌──────────────────────────────────────┐
│ KICKER              ① 아이템헤드      │
│ 타이틀 (4col)        │   설명          │
│ 설명                 ② …             │
│                     ③ …  (col5~11)   │
│                     ④ …             │
└──────────────────────────────────────┘
```
슬롯: `kicker, title, desc, items[4]{head, desc}`

## kpis — 핵심 지표 (히어로 1 + 서브 3 + KI 밴드)

```
┌──────────────────────────────────────┐
│ KICKER / 타이틀(어서션)               │
│ ┌히어로(5col)──┐ ┌서브 로우(7col)──┐  │
│ │ 라벨      칩 │ │ 칩 라벨    값 ▲% │  │
│ │ 186 억원     │ │ ─────────────── │  │
│ │ ▲21.6% YoY  │ │ 칩 라벨    값 ▲% │  │
│ │ 한줄 설명    │ │ 칩 라벨    값 ▲% │  │
│ └─────────────┘ └────────────────┘  │
│ ▐ KEY IMPLICATION 밴드 (12col)        │
└──────────────────────────────────────┘
```
슬롯: `hero{icon, label, value, unit, delta, deltaDir, note, desc}`,
`subs[3]{icon, label, value, unit, delta, deltaDir}`, `summary{head, bullets[]}`
히어로 원칙: 슬라이드의 주인공 지표 하나만 statHero(64pt Light)로 키우고 나머지는 로우로 강등.
KI 밴드는 HRD 시그니처(화이트 카드 + royal 좌측 바 + 라벨)로 렌더된다.
